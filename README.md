# blog
Personal blog dedicated to cybersecurity and secure software engineering, exploring ideas to improve the current state of the art and strengthen the industry's security posture, especially in Kazakhstan.

## Description
Source files are formatted according to the GitHub Flavored Markdown (GFM Spec) and organized within the /posts directory.

Technical documentation and visuals rely on local media storage located in /assets alongside external hyperlinks for source references and repositories; these graphics are produced using GIMP for image compression and conversion, Draw.io for vector diagrams, and Google Gemini for generating draft memes and illustrations. 

To ensure high-quality content without basic mistakes, the editing workflow leverages both Google Gemini and local LLMs for automated translation, grammar correction, and text/code refactoring.
