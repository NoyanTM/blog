# blog

## Description

Personal blog about cybersecurity and secure software engineering. These materials will be used for topic-specific scientific research (e.g., security of agentic systems, software supply chain security, threat intelligence and hunting). Also, I am iteratively working toward cutting-edge experiments and original discoveries including building my own custom systems, rather than only covering external sources and providing theoretical content. I want to be transparent in sharing of my thoughts and processes, but mistakes can happen - so feedback is always welcome.

- `/posts` - *.md files of publications that are formatted in [CommonMark](https://spec.commonmark.org/).
- `/assets` - different local attachments and media content, external materials are attached as hyperlinks and in-text references.
- `/scripts` - ... 

## Tools

I use local SLMs in llama-cpp inference and Google Gemini services for editing mistakes in texts and creating translations as drafts from Russian to English. Also, I apply additional and supplementary tools:
- GIMP for image compression and conversion.
- FFMPEG and Kdenlive for video editing and convertion.
- YT-DLP for downloading external videos (e.g., from YouTube).
- Google Gemini services and ComfiUI for generating and editing illustrations.
- Draw.io for creating vector diagrams.
- VSCode editor for writing code and text. 
- And so on...
